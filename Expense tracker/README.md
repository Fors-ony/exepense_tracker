# Python CLI Expense Tracker
A lightweight interactive command line application built with python to manage and track daily expenses

#Features
- Add expenses:Log purchases with descriptions and amounts.
- View Expenses:Display a list of all recorded entries.
- Total Expenses:Calculate the cumulative total spent automatically.
- Interactive menu

# Concepts used
- Control loops ('while True')
- Conditional logic (if, elif, else)
- Data Structures (Lists and Dictionaries)
- Python f-strings

# How to Run
1. Make sure python 3.x is installed.
2. Clone or download this repository.
3. Run the script in your terminal:
   '''bash
   python expense_tracker.py
